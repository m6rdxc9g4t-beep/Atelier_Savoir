Installer et connecter Claude Code

Dans un terminal, installez Claude Code puis connectez-vous une fois avec votre compte Claude :

curl -fsSL https://claude.ai/install.sh | bash
claude

Si une variable ANTHROPIC_API_KEY est définie sur votre Mac, l'app l'ignore pour utiliser votre abonnement.
